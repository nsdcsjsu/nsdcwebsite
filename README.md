# AI Genesis Hacks 🚀

**Impact. Security. Intelligence.**

## 🎯 Tracks

**🌍 Impact**
Build technology that makes a real difference in people's lives. Projects can tackle education, health, accessibility, sustainability, or community support.

**🔒 Security**
Build technology that keeps people, data, and systems safe. Projects can focus on privacy, cybersecurity, fraud prevention, or digital safety.

**🧠 Intelligence**
Build technology powered by AI and machine learning. Projects can use AI to solve problems, automate tasks, or create smarter experiences.

Teams choose **one track** when submitting, and every project is also eligible for **Best Overall**.

## 🏆 Awards
